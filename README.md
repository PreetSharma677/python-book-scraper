# Python Book Scraper

A Python script that scrapes book data from a website and saves it to a CSV file.

## What it does
- Sends a request to the website using Requests
- Reads the page and finds the book details using BeautifulSoup
- Saves the results to a CSV file

## Libraries used
- requests
- beautifulsoup4
- csv (built into Python)

## How to run
1. Install Python 3
2. Install the libraries:

   pip install requests beautifulsoup4

3. Run the script:

   python scrape.py

## Output
A CSV file with the book data.
